# 🐾 Patulandia - Sitio Web

Proyecto realizado para la materia Programación IV.

Este sitio web fue desarrollado como trabajo práctico académico con el objetivo de crear una página web de baja complejidad utilizando HTML, CSS y JavaScript, incorporando navegación entre páginas, diseño responsivo e interacción con el usuario.

Patulandia es un sitio pensado para ofrecer una experiencia divertida e informativa, con una estética propia y secciones organizadas para facilitar la navegación.

El sitio puede visualizarse online mediante GitHub Pages.
Patulandia es una página web desarrollada con tecnologías web básicas, enfocada en aplicar los conocimientos adquiridos durante la cursada de Programación IV.

El proyecto incluye diferentes secciones conectadas mediante un sistema de navegación intuitivo, permitiendo recorrer el contenido de manera sencilla y agradable.
